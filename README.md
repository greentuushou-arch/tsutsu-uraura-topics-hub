# にっぽん津々浦々 気になる特集 / 津々浦々レシピ

楽天市場店「にっぽん津々浦々」のトピックスページ
（https://www.rakuten.co.jp/tsutsu-uraura/contents/topicslist/ ）を
「気になる特集」「津々浦々レシピ」の2ブロックに整理し直した一覧ページです。

- レイアウト・モーションのベースは https://min-kura.com/ の構造解析
  （ヘッダー透過オーバーレイ／円形FVカルーセル／罫線つき台帳グリッド／ホバーで背景色が切り替わるカード 等）
- 配色はベージュ＋差し色ピンク＋黄緑の和紙・わら半紙トーン
- 記事データ・サムネイル画像は元トピックスページの実データ
- タイトル先頭の「【レシピ】」で自動的にレシピ／特集に振り分け
- 類義語対応の検索窓つき（例：「麺」で検索するとうどん・そば・ラーメン等もヒット）

---

## ファイル構成

```
index.html      … ページ本体（HTML/CSS/JS）
articles.js     … 記事データ（レシピ/特集の元になる一覧）★更新のたびに書き換わるファイル
update.mjs      … articles.js を最新の状態に作り直すスクリプト
images/         … イラスト・ロゴ画像
```

`index.html` は `articles.js` を読み込んで記事一覧を表示しています。
**新しい記事が増えたときは、この `articles.js` を最新の内容に更新するだけ**で、
ページ本体（`index.html`）は一切さわる必要がありません。

---

## 新しい記事ができたときの更新方法

方法は2つあります。**どちらか一方だけ**で大丈夫です。

### 方法A：スクリプトで自動更新（おすすめ）

パソコンに Node.js（18以降）が入っていれば、コマンド1つで完結します。

1. このフォルダ一式をパソコンに置く（すでに公開済みのものを更新する場合は、
   フォルダごとダウンロードするか `git pull` する）
2. フォルダの中でターミナル（コマンドプロンプト）を開き、次を実行

   ```
   node update.mjs
   ```

3. 「にっぽん津々浦々」のトピックスページに今載っている記事を**すべて自動で取得し直し**、
   `articles.js` を新しく作り直します。新しく追加された記事はもちろん、
   記事タイトルの変更・削除も自動的に反映されます。件数が多いので数秒〜十数秒かかります。
4. 実行後に表示される件数（レシピ◯件／特集◯件）を確認し、`index.html` と一緒に
   サーバーへアップロード（またはGitHubへpush）してください。

> Node.jsが入っていない場合は https://nodejs.org/ からLTS版をインストールしてください
> （インストーラーに従って「次へ」を押していくだけで完了します）。

### 方法B：手作業で1件だけ追加する

スクリプトを使わず、新しく公開した記事1件だけをその場で追加したい場合は、
`articles.js` をテキストエディタで開いて、配列の**先頭**に1行追加してください。

```js
const ARTICLES=[
  ["記事のURL","サムネイル画像のURL（?fitin=以降は無しでOK）","記事タイトル",0か1],
  ... 既存のデータがこの後に続く ...
];
```

- 1つ目：記事ページのURL
- 2つ目：サムネイル画像のURL（`https://tshop.r10s.jp/.../〇〇.jpg` の部分。末尾に `?fitin=600:337`等が
  付いていたら、その部分は消してOKです）
- 3つ目：記事タイトル（「【レシピ】」や「｜にっぽん津々浦々」などの飾り部分は無くてOK。
  そのまま入れても表示上問題ありません）
- 4つ目：**レシピなら `1`、特集なら `0`**

追加例（レシピ記事を1件追加する場合）：

```js
const ARTICLES=[
  ["https://www.rakuten.co.jp/tsutsu-uraura/contents/new-recipe-page/","https://tshop.r10s.jp/tsutsu-uraura/cabinet/content-pages3/new-thumb.jpg","新しいレシピのタイトル",1],
  // ↑ここに1行追加。この下に既存の行がそのまま続く
  ["https://www.rakuten.co.jp/tsutsu-uraura/contents/column/gotouchi/","https://tshop.r10s.jp/tsutsu-uraura/cabinet/content-pages2/imgrc0107063115.jpg","にっぽん津々浦々厳選！スタッフ激推し「にっぽんの味」47選",0],
  ... （既存の行がこの後も続く）
];
```

一番手前（先頭）に追加すると、ページの「Pickup」やカード一覧の先頭付近に新しい記事として表示されます。

## 反映（アップロード）について

GitHub Pages で公開している場合は、`git add` → `git commit` → `git push` するだけで、
数分以内に本番ページへ反映されます。別のサーバーにアップロードしている場合は、
`articles.js`（方法A・Bどちらの場合も）と、変更していれば `index.html` を
サーバー上の同じ場所に上書きアップロードしてください。

---

## 検索キーワードを増やしたいとき（おまけ・任意）

検索窓は「類義語」に対応しています。たとえば「麺」と検索すると、うどん・そば・ラーメン・
パスタ・そうめん等の記事もまとめてヒットします。この対応関係は `index.html` 内の
`SYNONYMS` という辞書（連想リスト）で管理しています。新しいジャンルの記事が増えて
「〇〇で検索したらヒットしてほしい」という語があれば、`SYNONYMS` に1行追加することで
対応できます（この作業はコードの編集になるため、必要であれば制作担当までご連絡ください）。

## 困ったときは

- `node update.mjs` を実行してエラーが出た場合は、エラーメッセージをそのまま
  制作担当（GREEN通商）まで送ってください。楽天側のページ構造が変わった際に
  調整が必要になることがあります。
- 記事の分類（レシピ/特集）がおかしい場合は、記事タイトルの先頭が「【レシピ】」に
  なっているかをまず確認してください（このタグの有無で自動判定しています）。
