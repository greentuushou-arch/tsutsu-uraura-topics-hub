# にっぽん津々浦々 気になる特集 / 津々浦々レシピ

楽天市場店「にっぽん津々浦々」のトピックスページ
（https://www.rakuten.co.jp/tsutsu-uraura/contents/topicslist/ ）を
「気になる特集」「津々浦々レシピ」の2ブロックに整理し直した一覧ページ。

- レイアウト・モーションのベースは https://min-kura.com/ の構造解析
  （ヘッダー透過オーバーレイ／3枚ピーク型カルーセル／ホバーで背景色が流し込まれるアーカイブカード等）
- 配色はベージュ地＋差し色ピンク(#ff9999)＋黄緑の和紙・わら半紙トーン（SVGノイズで紙の質感を付与）
- FVは円形フォトの3枚ピークカルーセル。中央の写真から少し離れた位置に黒い縁（リング）を配置
- 記事データ・サムネイル画像は元トピックスページの `window.__INITIAL_STATE__` から取得した**全429件の実データ**
- タイトル先頭が「【レシピ】」の記事を RECIPE、それ以外を FEATURE として自動分類（特集360件／レシピ69件）
- 「気になる特集」「津々浦々レシピ」を別ブロックとして表示。各ブロックは12件ずつ「もっと見る」で追加読み込み
